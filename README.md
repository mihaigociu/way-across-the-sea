# The Way Across the Sea

An educational browser game for children (10–14) about how Christianity spread across the Roman world, from Pentecost to Nicaea (AD 30–330). It is told through the eyes of a seafaring family of early Christians, in English and Romanian.

**Play the prototype:** https://mihaigociu.github.io/way-across-the-sea/

- [`PLAN.md`](PLAN.md): the game plan (vision, audience, characters, chapters, mechanics, roadmap)
- [`game/`](game/): the prototype, an ancient-style map of the Mediterranean with an introduction ("The story so far") and Paul's First Journey. See [`game/README.md`](game/README.md) to run it locally.
